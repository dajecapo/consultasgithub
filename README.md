# Galería de Sabios - Formulario de Consulta (GitHub Pages)

Este formulario permite a cualquier usuario hacer una consulta a un sabio directamente desde la web, usando un formulario alojado en GitHub Pages y conectado a una hoja de cálculo de Google Sheets mediante Apps Script.

## 🌐 Enlace público

Puedes acceder a esta versión funcional desde:

```
https://dajecapo.github.io/adopta-un-sabio/consultas_funcional_github.html
```

## ✨ Características principales

- Validación completa de campos:
  - Teléfono (10 dígitos)
  - Email con formato correcto
  - Campo de pregunta con límite de 50 palabras
  - Fecha seleccionada con calendario
  - Captcha de suma aleatoria
  - Confirmación "No soy un robot"
- Estilo profesional, limpio y responsive
- Mensaje de éxito y limpieza automática del formulario
- Conexión directa a Google Sheets sin errores CORS

## 🔗 Conectado a:

**Apps Script Web App:**
```
https://script.google.com/macros/s/AKfycbyGS-uQR4qn_LjAXghsTBirHton-35HA4AK7GdKm-MEumcZmWE4L7vJ0M1EaHzEkghY/exec
```

**Hoja de cálculo destino:**
```
Nombre | Telefono | Email | Pregunta | Fecha
```

Incluye una hoja "LOG" que registra todos los envíos como respaldo técnico.
